# React Performance & UI Patterns

Small, self-contained implementations of common frontend machine-coding problems and performance patterns in React.

| Pattern | Folder |
|---|---|
| Debounce hook (`useDebounce`) | `src/debounce` |
| Throttle | `src/throttle` |
| Autocomplete / typeahead | `src/features/autoComplete` |
| Infinite scroll | `src/features/infiniteScroll` |
| Concurrent progress bars | `src/features/concurrentProgressBar` |
| OTP input | `src/features/otp` |
| Timer | `src/features/timer` |
| Toast notifications | `src/features/toastNotification` |

```bash
npm install
npm run dev
```
